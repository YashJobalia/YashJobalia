## About Me

I'm a full-stack software engineer focused on building scalable, multi-tenant enterprise applications. At **Radian Group**, I contribute across architecture, frontend development, backend services, authentication, data-intensive workflows, and cloud delivery. I also apply LLM-assisted workflows to implementation, debugging, testing, code review, and documentation.

Previously, I developed full-stack business applications at **Farsoft Infotech** using React, Java, Spring Boot, JavaScript, SQL, and MongoDB. I hold an M.S. in Computer Science from **George Mason University**.
